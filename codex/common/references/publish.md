# 릴리스
사용자가 요청한 릴리스 범위와 실제 배포 설정·트리거·자격증명 주입·버전 규칙을 확인한다. 특정 레지스트리·브랜치·태그 이름을 가정하지 않는다.
먼저 변경 요약·버전·공개 API·소비자 영향·검증 결과를 review 가능한 상태로 준비한다. commit·push·tag·release·publish는 요청에 포함된 작업만 수행한다. 예제 명령이나 Skill 호출 자체를 모든 외부 작업의 승인으로 해석하지 않는다.
DoD: 버전/변경 내역/가이드 정합성, 필수 검사, 배포를 실행했다면 실제 결과, 소비자 조치. 준비만 끝났으면 배포 완료라고 보고하지 않는다.
