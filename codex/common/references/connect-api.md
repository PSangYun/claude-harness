# 외부 데이터/API 연결
명세·기존 client·인증·오류·DTO 변환·캐시·취소 패턴을 확인하고 연결 지점을 목록화한다. 명세의 필드/nullable/호출 의미를 유지하고 필수 계약은 추측하지 않는다.
상태 변경 결과가 불명확하면 실패로 단정해 무조건 재전송하지 않는다. 멱등성·서버 중복 방지·명확한 재시도 조건을 계약에서 확인한다. 시크릿은 기존 환경/보안 저장소 경로로 주입하고 로그에 남기지 않는다.
DoD: 연결 대상과 명세 대응, 로딩/오류/성공 처리, 관련 캐시/취소, DI/설정 연결, 필요한 검사 통과, 실제 서버 테스트 범위와 생략 항목 보고.
