# DoD 판정
요청 범위의 완료 조건과 실제 diff·staged·untracked 파일을 확인한다. 각 조건에 파일:라인이나 명령 실행 결과를 붙여 PASS/FAIL/확인 불가로 판정한다. maker의 요약만으로 PASS를 주지 않는다.
독립 checker는 코드를 수정하지 않고 판정만 한다. 독립 실행이 불가능하면 자가 검증이라고 표시한다. 환경·권한·기기 부재는 확인 불가로 기록하며 전체 DoD의 PASS 근거로 쓰지 않는다.
verify 결과는 설정된 검사 집합에 한정된 결과다. UI 렌더링·실제 서버·기기 실행·공개 API 호환성은 필요한 경우 별도 확인한다. 같은 변경의 검증 결과가 이미 있고 이후 관련 코드가 안 바뀌었으면 중복 실행하지 않는다.
결과 형식: 조건 | PASS/FAIL/확인 불가 | 근거. 필수 조건이 미확인이면 전체 완료 판정을 내리지 않는다.
