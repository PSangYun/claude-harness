# UI 설계/구현
요청된 디자인·스크린샷·설명을 확인하고 요소·variant·상태·반응형/접근성 범위를 정리한다. Figma 입력이 있을 때만 사용 가능한 연결과 관련 Figma Skill을 사용한다.
기존 컴포넌트·스타일·토큰을 재사용하고 새로운 디자인 시스템이나 라이브러리를 요구하지 않는다. 디자인 값의 출처와 확인 못한 부분을 구분한다. UI 전용 단계에서는 업무/API를 TODO로 남긴다.
DoD: 요소/상태 대응, 기존 컴포넌트 재사용, 실제 검사 통과, 요청한 UI 범위에 맞는 렌더/상호작용 확인 여부. UI가 없는 요청에는 적용하지 않는다.
