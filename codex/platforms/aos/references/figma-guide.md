# 디자인 입력 확인
Figma URL이 있으면 연결된 도구와 관련 Figma Skill로 대상 노드·스크린샷을 확인한다. 특정 file key·사용자 토큰·회사 컴포넌트 이름을 전제하지 않는다.
visible·variant·레이아웃·글꼴·색상 변수·effects를 제공된 디자인 데이터에서 확인하고 실제 프로젝트의 대응 토큰에 매핑한다. 이미지의 색만 보고 variant를 단정하지 않는다.
기존 스타일을 재사용하되 화면별 크기·간격이 같다고 가정하지 않는다. 사용자 요청이 스크린샷/설명 기반이면 Figma 연결을 필수로 요구하지 않는다.
구현 후 가능한 환경에서 렌더링을 비교하고 측정 근거와 미확인 값을 구분한다. 연결되지 않은 도구를 호출했다고 보고하지 않는다.
