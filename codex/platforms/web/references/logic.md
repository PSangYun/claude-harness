# Web 앱 동작 단계

기능 정의의 입력·검증·상태 전이·오류·이동을 목록화한다. 실제 프로젝트의 상태 관리·폼·라우터 패턴을 사용한다.
API는 타입과 스텁을 유지하고 네트워크 구현은 connect-api 단계로 남긴다. 중복 제출과 비동기 취소·수명 처리를 확인한다.

## Definition of Done

1. 동작 목록과 코드가 전수 대응한다.
2. 입력 검증·로딩·오류·이동 상태가 요구사항대로 동작한다.
3. 신규 네트워크 구현이 없고 연결 지점에 TODO가 있다.
4. 타입 검사·lint·변경된 순수 로직의 관련 테스트가 통과한다.
5. 실제 상호작용을 확인했는지와 미검증 부분이 구분돼 있다.
