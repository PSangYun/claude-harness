# Web 앱 API 연결 단계

명세와 TODO를 대조하고 실제 HTTP client·인증·query/mutation 패턴을 확인한다. 요청/응답 타입과 nullable을 명세대로 유지한다.
DTO 변환·오류 처리·캐시 invalidation·취소·중복 제출을 기존 규칙에 맞춰 연결한다. URL·키는 기존 환경변수 주입을 사용하고 클라이언트 번들에 서버 비밀을 넣지 않는다.
상태 변경 요청은 서버가 중복 방지를 보장하지 않으면 자동 재시도하지 않는다. 실제 서버 변경은 승인된 테스트 범위에서만 실행한다.

## Definition of Done

1. 연결 대상 TODO가 해소됐거나 남은 사유가 명시돼 있다.
2. 요청·응답 필드가 명세와 일치하고 계층 경계가 유지된다.
3. 로딩·오류·성공·캐시 갱신이 호출 지점마다 처리된다.
4. 타입 검사·lint·관련 테스트가 통과한다.
5. 하드코딩된 비밀이 없고 실제 API/브라우저 확인 여부가 보고돼 있다.
