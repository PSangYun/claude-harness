# Web 앱 기능 스캐폴딩

실제 framework·폴더 구조·유사 기능·라우팅·상태·API 계층을 먼저 확인한다. 기능명·진입점·범위를 기존 요청에서 확인하고 모르는 필수 값만 묻는다.
기존 패턴대로 컴파일 가능한 페이지·컴포넌트·타입·필요한 hook/API 스텁을 만든다. UI 디테일과 API 연결은 별도 단계다. 프로젝트가 FSD Lite이면 레이어 방향을 지킨다.

## Definition of Done

1. 요청 범위와 파일 위치·이름이 기존 유사 기능과 일치한다.
2. 라우팅/공개 export/의존 연결에 빠진 부분이 없다.
3. 타입 검사·존재하는 lint가 통과한다.
4. 업무·네트워크 동작이 임의로 추가되지 않고 TODO 스텁이 명확하다.
