# Web 앱 UI 단계

Figma의 요청된 화면과 변형을 읽고 요소 목록을 만든다. design-system.md와 실제 `@itandsy/react-common` 의존/export를 확인하고 컴포넌트·토큰을 재사용한다.
프로젝트의 Server/Client Component 경계를 유지하고 필요한 최소 상태만 둔다. 업무·네트워크 로직은 TODO로 남긴다. 반응형은 프로젝트가 지원하는 화면 범위를 기준으로 검증한다.

## Definition of Done

1. 요청된 요소·변형 목록과 구현이 전수 대응한다.
2. 공통 컴포넌트를 중복 구현하지 않고 기존 토큰을 사용한다.
3. 타입 검사와 실제 lint가 통과한다.
4. API·업무 동작이 추가되지 않았다.
5. 사용 가능한 브라우저에서 지원 viewport를 확인한다. 브라우저가 없으면 렌더링 항목은 미검증이다.
